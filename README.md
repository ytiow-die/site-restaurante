# Sabor Caseiro — Site de restaurante

Projeto fictício desenvolvido para fins educacionais com **HTML5 e CSS3**.

## Objetivo
Criar uma página simples e responsiva para apresentar um restaurante, sua história, itens de cardápio e informações de contato.

## Funcionalidades
- Navegação entre as seções da página.
- Apresentação do restaurante.
- Cards com pratos e preços fictícios.
- Área de contato demonstrativa.
- Layout adaptável para celulares e computadores.

## Tecnologias utilizadas
- HTML5
- CSS3

## Como visualizar
1. Baixe ou clone este repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` em um navegador.

## Observação
Nome, restaurante, endereço, telefone, pratos e preços são fictícios. Este projeto não representa um estabelecimento real.
